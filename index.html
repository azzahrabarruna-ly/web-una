TUGAS PENGEMBANGAN

Yang Harus Dimodifikasi Kelompok

  1. Ubah tampilan agar memiliki identitas/desain kelompok sendiri.
  2. Gunakan data sintetis minimal 12–20 pasien dan 4–8 mesin HD.
  3. Pastikan sesi pagi dan sesi siang terlihat jelas.
  4. Tambahkan minimal satu fitur atau peringatan baru.
  5. Unggah seluruh folder ke GitHub dan deploy ke Netlify.
  6. Pastikan link Netlify dapat dibuka dari browser/HP.
